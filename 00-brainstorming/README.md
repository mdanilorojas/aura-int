# 00 Brainstorming

Espacio para explorar ideas de negocio, contexto del equipo, restricciones, filtros, oportunidades y recomendaciones iniciales.

## Estructura

### `01-criterios-base`

Aqui vive el archivo editable que controla el scoring:

- `criterios-base-ideas.md`
- `evaluation-process-v1.1.md`
- `evaluation-process-v1.1.html`

Cuando quieras recalibrar el analisis, edita ese archivo primero.

### `02-visuales-generados`

Aqui viven los HTML navegables generados a partir del brainstorming.

Versiones actuales:

- `Kickoff doc v1.1.html`

Las futuras versiones visuales de ideas rankeadas deben guardarse aqui.

### `03-documentos-fuente`

Aqui viven los documentos fuente e historicos del proceso:

- kickoff docs en Markdown;
- recomendacion experta;
- sintesis del proceso de evaluacion.

Estos archivos explican de donde viene el analisis, pero el archivo que se edita para regenerar nuevas versiones es `01-criterios-base/criterios-base-ideas.md`.
